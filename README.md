# Wayfare — AI travel agent

Describe a trip in plain words ("6 days from Delhi for 2 people under ₹50K, nature and food, relaxed")
and get a practical plan that fits your budget and pace — and adapts when you change your mind.

## Development

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # lint + typecheck + tests
npm run build
```

Full documentation is on the way as the agent is built out.
